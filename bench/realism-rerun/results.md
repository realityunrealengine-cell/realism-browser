# Realism Browser — сравнение потребления ресурсов

Машина: Intel64 Family 6 Model 191 Stepping 2, GenuineIntel, 16 логических ядер. Каждый запуск — новый временный профиль, окно 1280×800, одинаковые URL и время ожидания. Память — сумма по **всему дереву процессов** браузера. Значения — медиана по запускам (в скобках min–max).

* **RAM** — private working set (столбец «Память» в Диспетчере задач), МБ
* **Commit** — выделенная приватная память, МБ
* **CPU** — средняя загрузка всех ядер за окно измерения, %
* **Запуск** — время до появления окна, мс
