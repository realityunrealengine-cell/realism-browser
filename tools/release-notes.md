## Realism Browser 1.1.0

**Новое**
- Система обновлений: меню ⋯ → «Проверить обновления», автоматическая проверка раз в день, скачивание с проверкой SHA-256 и установка с перезапуском браузера (вкладки сохраняются).
- Монитор ресурсов: блок «Как сверить с Диспетчером задач» — память интерфейса (`realism.exe`) и движка WebView2 (`msedgewebview2.exe`) отдельно, с PID.

**Исправлено**
- Разворачивание окна на весь экран кнопкой в заголовке (раньше окно оставалось со старой раскладкой и чёрными областями).
- Фоновые вкладки, открытые в фоне, теперь замораживаются (TrySuspend не срабатывал для ни разу не показанных вкладок).
- Страницы без собственного фона получают белый холст, как в других браузерах.

**Установка:** скачайте `Realism-Browser-Setup.exe` и запустите. Права администратора не нужны. Файл не подписан — SmartScreen может предупредить («Подробнее → Выполнить в любом случае»).

SHA-256 установщика — в `SHA256SUMS.txt`.
